Built for a wall of agents

Everything you need to run, watch, and stay focused across many sessions.

◤Attention detection

A pure Rust engine reads the PTY stream and classifies each session RUNNING / IDLE / WAITING using OSC 133 markers plus an activity heuristic.

◤Focus dashboard

A "needs you" zone surfaces blocked sessions so you never hunt three tabs deep for the one asking a question.

◤Real terminal

xterm.js with the WebGL renderer over portable-pty. A full shell, not an emulated subset.

◤Command blocks

Warp-style per-command blocks with a status gutter, sticky header, and hover toolbar.

◤Focus timer

A Pomodoro-style focus/break loop with progress rings, a daily goal, and break prompts.

◤History autofill

Inline ghost suggestions drawn from your real command history as you type.

◤Native notifications

macOS alerts when a session finishes a long command or starts waiting on you.

◤Themes & sharp UI

Dracula, Catppuccin, Tokyo Night, Nord, One Dark and more — in a fully squared, terminal-native interface.

◤Local-first

SQLite (WAL) persistence via rusqlite. Your data never leaves your machine.

Download

macOS & Linux · MIT licensed.

macOS

Download .dmg — Apple Silicon All releases →

Open the .dmg and drag Aran Terminal into Applications. The build is not yet notarized, so on first launch right-click the app → Open (or run xattr -dr com.apple.quarantine "/Applications/Aran Terminal.app") to get past Gatekeeper.

Linux

Download .deb — Debian / Ubuntu Download .AppImage — Any distro
Download .rpm — Fedora / RHEL All Linux releases → 
# Debian / Ubuntu (.deb)
sudo dpkg -i Aran.Terminal_2.3.1_amd64.deb
sudo apt-get install -f   # fix any missing deps

# Fedora / RHEL (.rpm)
sudo rpm -i Aran.Terminal-2.3.1-1.x86_64.rpm

# Any distro (.AppImage)
chmod +x Aran.Terminal_2.3.1_amd64.AppImage
./Aran.Terminal_2.3.1_amd64.AppImage

On Ubuntu/Debian you also need the WebKit and GTK runtime libraries. If the .deb install reports missing dependencies, run sudo apt-get install -f to pull them automatically. For other distros, make sure libwebkit2gtk-4.1, libgtk-3, and libayatana-appindicator3 are installed.

Build from source

Requires Rust toolchain and Node.js 18+.

# clone and enter the app
git clone https://github.com/arunkarnann/aran-terminal.git
cd aran-terminal/conductor
npm install

# run in development (hot reload)
npm run tauri dev

# or build a release bundle
npm run tauri build

The release bundle lands in conductor/src-tauri/target/release/bundle/. On macOS this produces a .app and .dmg; on Linux it produces .deb, .rpm, and .AppImage files.
